  <h1>All Cost Calculators</h1>
  <p>Every calculator on this site is free, with no sign-up. Pick a job, answer a few questions, and see your low, typical, and high price in seconds. All prices are sample estimated USA ranges. Each calculator shows its own breakdown of material, labor, supplies, and equipment, so you can check the math line by line. Prefer to read first? See the <a href="{{ '/blog/' | relative_url }}">cost guides</a>, where each guide explains what moves the price up or down and links to its calculator.</p>
  <h2>How to use the calculators</h2>
  <p>Pick the job you want to price, then answer the few questions on its page. A movers price needs your home size and distance, a roof price needs the roof size and material, a fence price needs the length, material, height, and gates, an oil change needs the oil type and vehicle type, central air needs the home size and efficiency, a car wrap needs the vehicle size, wrap type, and finish, and house painting needs the job type and home size. No calculator asks for your name, email, or address, and every calculation happens in your browser.</p>
  <h2>How the low, typical, and high ranges work</h2>
  <p>Each calculator shows three bands. Low is a smaller job with basic choices, typical is the most common result at typical USA rates, and high is a larger job, premium choices, or extra services. Below the bands, an itemized breakdown splits the total into material, labor, supplies, and equipment, so you can check the math line by line. The bands update with your choices, so change one input and the range moves with it.</p>
  <h2>Why prices are ranges, not quotes</h2>
  <p>Your real price depends on your size, your materials, and where you live, so a single number would mislead you. A roof in a big city costs more than the same roof in a small town, and a premium material costs more than a basic one. The range shows that spread, and the breakdown shows where it comes from. Use the range to check quotes from local pros: ask each pro for a written quote for the same size and options, compare the quotes line by line against the breakdown, and always get 3 quotes before you hire anyone.</p>

  function linkList(items) {
    var ul = document.createElement("ul");
    items.forEach(function (p) {
      var li = document.createElement("li");
      var a = document.createElement("a");
      a.href = root + p.url;
      a.textContent = p.name;
      li.appendChild(a);

     Paint a Car guide first. */
  function scorePage(p, words) {
    var title = p.name.toLowerCase();
    var titleWords = title.split(/[^a-z0-9]+/);
    var keys = p.keys.toLowerCase();
    var keyWords = keys.split(/[^a-z0-9]+/);
    var s = 0;
    words.forEach(function (w) {
      if (!w) return;
      if (titleWords.indexOf(w) !== -1) { s += 3; }

      if (keyWords.indexOf(w) !== -1) { s += 2; }
      else if (keys.indexOf(w) !== -1) { s += 1; }
    });
    return s;
  }
